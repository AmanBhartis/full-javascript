Truthy and False values in javascript

In JavaScript, values can be categorized as "truthy" or "falsy" based on how they are evaluated in a boolean context. A value is considered "truthy" if it evaluates to true when used in a boolean context, and "falsy" if it evaluates to false.

Here are some examples of truthy and falsy values in JavaScript:

Truthy values

  • `true`
  • `1`
  • `"hello"`
  • `[1, 2, 3]`
  • `{a: 1}`

Falsy values

  • `false`
  • `0`
  • `""` (empty string)
  • `null`
  • `undefined`
  • `NaN`
